## Teşhis (özet)
1. Katalog CTR'si SAĞLIKLI (%6–12). Düşük görüntüleme kanal geneli thumbnail sorunu DEĞİL.
2. Tek yeni video (IMSI/PICSI) paketleme yüzünden battı — izole vaka.
3. Shorts CTR'si (%1–3) format gereği düşük; abone getirmiyor.
4. Asıl görüntüleme düşüşü = dağıtım/trafik (önerilen −%23, arama −%20).

## Aksiyon Kuralları (öncelik)
1. **Zayıf açılan videoyu hemen kurtar:** CTR <%3 ise Studio → İçerik → video → "Küçük resim testi"; 3 alternatif kapak + başlık.
2. **Başlık:** ilk kelimeler hasta dilinde fayda/merak + soru. Kısaltma/jargon ile başlama.
3. **Arama −%20 telafisi:** arama getiren evergreen soru-videoları üret; düşen videolarda açıklama/etiket tazele.
4. **Önerilen −%23 telafisi:** bitiş ekranı + kartla yüksek CTR'li videoları birbirine bağla; oturum süresini uzat.
5. **Koru:** bölümlü açıklama, blog linki + UTM, hashtag, çok dilli altyazı.
6. **Shorts'u yeniden değerlendir:** abone/dönüşüm getirmiyorsa frekansı azalt veya huni (uzun videoya yönlendirme) olarak kurgula.
