# 07 — Description Library

> Her video için description'ı sıfırdan yazma. Süre kategorisini (`03-script-format-checklist.md` K1-K5) ve konu tipini seç → ilgili iskeleti kopyala → modülleri yerleştir → hashtag/disclaimer/UTM doldur. **Standart şablon = tutarlı tarama + tutarlı algoritma sinyali.**

`channel-operations-memory-2026-05-01.md` not: "video açıklama şablonunu tüm videolarda standardize etmek bir sonraki doğal adım." Bu dosya o adımdır.

---

## Modül haritası

Bir description bu 8 modülden oluşur (sıralı):

| # | Modül | Zorunlu mu? | Notlar |
|---|---|---|---|
| 1 | **Snippet (ilk 150 karakter)** | Evet | Mobil arama snippet'i + Google video snippet — SEO hayati |
| 2 | **Makale CTA** | Evet (K2-K5) | UTM linkli; TR → tupbebek.com, FR → draksoyivf.com (cross-reference-policy §A) |
| 3 | **İçindekiler (chapter)** | Evet (K2-K5) | YouTube chapter marker; algoritma engagement sinyali |
| 4 | **Kaynaklar bloğu** | Evet (kanıt-temelli K2-K5) | Kılavuz adı + yıl; PMID/DOI mümkünse |
| 5 | **About blok** | Evet | Sabit metin; aşağıda hazır |
| 6 | **Disclaimer satırı** | Evet | Konu tipine göre 5 alternatif (`03-script-format-checklist.md` §4) |
| 7 | **Hashtag** | Evet | TR: 3-5; FR: 3-5; konu kümesi başına bankadan |
| 8 | **Sabitlenmiş yorum referansı** | Opsiyonel | Description'ın son satırı; pinned comment'a yön |

**Yasak modüller (cross-reference-policy §A + SB Tanıtım Yönetmeliği):** klinik adı, hekim adı, randevu/iletişim CTA, fiyat, "bana ulaşın", "garanti", "mucize", marka adı, hasta öyküsü, önce-sonra.

## Konu tipi modifikasyonları

Yukarıdaki K1-K5 iskeletleri **çatıdır**. Konu tipine göre snippet açısı, hashtag, disclaimer ve kaynak yoğunluğu değişir.

### Tip 1 — Kavram açıklayıcı (pillar bilgi)

**Örnekler:** "DHEA nedir", "Kisspeptin nedir", "AMH ne anlama gelir", "ERA testi nedir"

| Modül | Modifikasyon |
|---|---|
| Snippet açısı | "X nedir? Sade tanım + bilim güncel pozisyon" |
| Disclaimer | **Standart** — "Bu içerik bilgilendirme amaçlıdır; bireysel tıbbi değerlendirmenin yerini almaz." |
| Hashtag özlemi | Konunun ana hashtag'i + 1-2 ilgili kategori |
| Kaynak | 2-4 kılavuz + 1-2 RCT |

### Tip 2 — Pazarlama eleştirisi

**Örnekler:** "Wellness peptidleri", "BPC-157 / NAD / Epitalon", "Yumurtalık gençleştirme PRP", "Longevity klinik protokolleri"

| Modül | Modifikasyon |
|---|---|
| Snippet açısı | "Pazarlamanın söylediği X, bilim Y diyor. Dürüst tablo." |
| Disclaimer | **Onaysız ürün eleştirisi** — "Bu içerik bilimsel kanıt durumunu özetler; klinik kullanım onayı olmayan ürünler için tedavi önerisi içermez." |
| Hashtag | Konu + #kanıttemelli (TR) / #preuvesétifiques (FR); pazarlama dilinden kaçın |
| Kaynak | Düzenleyici (TİTCK/FDA/EMA) + sistematik review + master vault peptid hub atfı |
| Yasak | Belirli ürün adı / longevity klinik adı kullanılmaz; sınıf-bazlı dil |

### Tip 3 — Kılavuz / kanıt değerlendirmesi

**Örnekler:** "ESHRE 2023 IVF add-ons ne diyor", "NAMS 2023 menopozda neyi öneriyor", "ESHRE 2025 stimülasyon protokol güncellemesi"

| Modül | Modifikasyon |
|---|---|
| Snippet açısı | "[Kılavuz adı yıl]: ana 3 değişiklik / pratik klinik anlam" |
| Disclaimer | **Standart** veya **IVF prognoz** (eğer başarı oranı tartışılıyorsa) |
| Hashtag | #ESHRE / #NAMS / #NICE etiketi + konu |
| Kaynak | Kılavuzun tam başlığı + DOI; ESHRE/NAMS web'den open access link |
| Yapı notu | Beat B (kanıt) bölümü genişletilmiş; chapter 6-8 |

### Tip 4 — Hassas konu (METAFOR YASAK)

**Örnekler:** POI/POF, RPL, donör yumurta TR, kanser FP, ileri yaş düşük şans, RIF, kayıp

> `youtube-content/00-INDEX.md` "METAFOR YASAK" listesi + `youtube-responses/templates/13-17` ile paralel.

| Modül | Modifikasyon |
|---|---|
| Snippet açısı | Empati + bilgi; pazarlama-tipi lansman cümlesi yok |
| Disclaimer | **Hassas konu** — "Bu video belirli bir tanı için bireysel öneri içermez. Durumunuzu hekiminizle değerlendirmeniz, ileriye dair en sağlıklı adımdır." |
| Hashtag | Sade — duygu sömürüsü hashtag'i yok ("#mucize", "#umutmücadele" yok) |
| Kaynak | İlgili kılavuz + master vault concept sayfası (varsa) |
| Yapı notu | Beat D'de **anchor / aile üyesi metaforu yok**; sade-empatik kapanış |
| Sabitlenmiş yorum | Hassas konularda destek yönlendirmesi (varsa psikolojik destek hat satırı) |

## UTM kampanya konvansiyonu

| Alan | Değer |
|---|---|
| `utm_source` | `youtube` |
| `utm_medium` | `description` (ana video) / `shorts` (K1) / `pinned-comment` (sabitlenmiş yorum içinden link) |
| `utm_campaign` | `[pack-id]` (topic-pack varsa, ör. `peptid-longevity-2026-04`) veya `[video-slug]` (tek-video) |
| `utm_content` | Opsiyonel — A/B varyantı veya thumbnail varyantı için |
| `utm_term` | Boş — YouTube context'inde anlamsız |

**Pack-id formatı:** `[konu-küme]-[YYYY-MM]` — ör. `peptid-longevity-2026-04`, `eshre-2025-stimulation-2026-05`. Master `wiki/youtube/topic-packs/` klasör isimleriyle paralel.

**Tek-video slug:** dosya/url slug'ı — kebab-case, TR'de aksansız (ör. `dhea-vajinal-vs-sistemik`), FR'de aksanlar korunur (ör. `pma-apres-40-ans`).

## Snippet (ilk 150 karakter) yazma kılavuzu

Description'ın ilk 150 karakteri **Google video snippet** + **YouTube mobil snippet**. SEO için en kritik kısım. Kurallar:

1. **Anahtar kelime ilk 50 karakterde** — "ERA testi", "DHEA", "kisspeptin"
2. **Soruyu çerçeve** veya **vaadi söyle** — "İşe yarıyor mu?", "Ne diyor güncel kanıt?"
3. **Yıl referansı** — "2026'da", "ESHRE 2023 sonrası" — algoritma için tazelik sinyali
4. **70 karakter sonrası** — okuyucunun "devam et" diyeceği bir kanca
5. **Klikbeyt yok** — "Şaşıracaksınız", "Bilmediğiniz", "Sırrı"

### TR örnek snippet'ler

```
ERA testi 2026'da işe yarıyor mu? Simón 2016 ve Cochrane 2023 çalışmalarının dürüst özeti. Kimler için değerlendirilebilir, kimler için değil.
```

```
Wellness peptidleri (BPC-157, NAD damar, Epitalon) menopozda işe yarar mı? TİTCK/FDA durumu + bağımsız kanıt. Pazarlama vs bilim ayrımı.
```

```
40 yaş üstü tüp bebek başarı oranı: ortalamalar, kümülatif şans, sizin bireysel tabloyu ne değiştirir? Üç katmanlı dürüst çerçeve.
```

### FR örnek snippet'ler

```
Le test ERA est-il utile en 2026 ? Revue honnête : Simón 2016, Cochrane 2023. Pour qui envisager, pour qui pas — sans marketing.
```

```
Peptides wellness (BPC-157, NAD-IV, épitalon) en ménopause : ce qu'en disent vraiment les agences. Marketing contre science.
```

```
FIV après 40 ans : moyennes, taux cumulé, ce qui change votre tableau personnel. Cadre honnête en trois couches.
```

## Sabitlenmiş yorum ile ilişki

Description "📌 Sorularınızı yorumlara yazın; sabitlenmiş yorumda kaynak ve genel disclaimer var." satırı sabitlenmiş yoruma yön verir.

Sabitlenmiş yorum yapısı (kısa, paralel):

### TR sabitlenmiş yorum şablonu

```
👋 Merhaba! Bu video [konu] hakkında.

📚 Kaynaklar:
- [ana kılavuz/yıl + link]
- [destekleyici RCT/meta-analiz]

📖 Detaylı yazı: tupbebek.com/[slug]

⚠️ Bu içerik bilgilendirme amaçlıdır; bireysel tıbbi değerlendirmenin yerini almaz. Sorularınızı yoruma yazın, vakit oldukça yanıtlamaya çalışıyorum.
```

### FR sabitlenmiş yorum şablonu

```
👋 Bonjour ! Cette vidéo aborde [sujet].

📚 Sources :
- [guide principal / année + lien]
- [RCT/méta-analyse de soutien]

📖 Article détaillé : draksoyivf.com/[slug]

⚠️ Ce contenu est informatif. Il ne remplace pas une évaluation médicale individuelle. Vos questions en commentaire, je réponds quand le temps le permet.
```

> Tam disclaimer (4 dilde) ayrı sabitlenmiş **kanal yorumu**nda; per-video pinned comment kanal disclaimer'ı tekrar etmez. Bkz. `youtube-responses/disclaimer.md` + `editorial-rules.md` "Disclaimer politikası".

## Mevcut video backfill stratejisi

`channel-operations-memory-2026-05-01.md` ve `senaiaksoy-fr-next-session-brief-2026-05-02.md` notları:

- TR kanal: 72 video, sabitlenmiş yorumlar tamamlandı (72/72), playlist yapısı oturdu
- FR kanal: 91 video, başlık/açıklama optimizasyon dalgası tamamlandı; **bulk metadata yeniden çalıştırılmaması notu**

### Karar

- **Yeni videolar (bu kütüphane sonrası):** bu şablon birebir uygulanır
- **Mevcut TR 72 + FR 91 video:** bulk yeniden işleme **yapılmaz**; Analytics 28 gün sonrası karşılaştırması beklenir. Sadece **erken-strateji** ya da **uyumluluk-riski** olan eski videolar için seçici güncelleme (örn. peptid/longevity videolarında description yenileme — onaysız ürün eleştirisi disclaimer'ına geçiş).
- **Seçici güncelleme tetikleyicileri:** (1) mevzuat ihlali riski, (2) kanıt güncellemesi (yeni kılavuz), (3) dead link / yanlış UTM, (4) hashtag eski/yasak

### Süreç (seçici güncelleme)

1. Video listesi → tetikleyici filtreden geç
2. Her güncellenen videoya `_log` satırı: dosya `youtube-content/description-backfill-log-YYYY-MM.md` (ay başına yeni)
3. Aylık review'da değişiklik sayısı + Analytics etkisi gözden geçirilir
